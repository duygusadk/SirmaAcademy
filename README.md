## 📂 Projects

### 🏨 Hotel Room Reservation System
A console-based application that allows users to **book and cancel hotel rooms**, while administrators can manage reservations and view income reports.  
**Key concepts:** Encapsulation, File I/O, User Authentication.



---

### 📦 Inventory Management System
A comprehensive inventory and order management application with **interfaces, abstract classes, inheritance**, and **payment processing simulation**.  
Includes an **E-commerce Console Application** extension with shopping cart and payment options.  

**Key concepts:** Abstraction, Interfaces, Inheritance, File I/O.  



---

### 📂 Streams & Files – Java Exercises
A collection of small programs practicing **Java Streams** and **File operations**:  
- Word and character counts  
- File copying and merging  
- Serialization and deserialization  
- ZIP extraction  
- Directory size calculation  

**Key concepts:** Java I/O Streams, Collections, Exception Handling.
